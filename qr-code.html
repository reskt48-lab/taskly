🌐 Buka Aplikasi 📦 Repository

📲 Cara Install di HP:

  1. Scan QR Code dengan kamera HP
  2. Atau ketik manual: reskt48-lab.github.io/taskly
  3. Android: Menu ⋮ → "Add to Home screen"
  4. iPhone: Share 🔗 → "Add to Home Screen"
  5. ✅ Selesai! App muncul di home screen
