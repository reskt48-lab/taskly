📱 Generate PWA Icons

Klik tombol di bawah untuk generate semua ukuran icon yang diperlukan untuk PWA.

✅ Semua icon berhasil di-generate!

📋 Cara Menggunakan:

  1. Klik tombol "Generate All Icons"
  2. Klik tombol "Download All Icons"
  3. Icon akan otomatis terdownload
  4. Pindahkan semua file icon ke folder taskly
  5. Aplikasi siap di-install di HP! 🎉

📱 Cara Install di HP:

  1. Upload aplikasi ke hosting (Netlify/GitHub Pages)
  2. Buka URL di HP (Chrome/Safari)
  3. Akan muncul prompt "Add to Home Screen"
  4. Atau klik menu ⋮ → "Install app"
