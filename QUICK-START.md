## 🆘 TROUBLESHOOTING

**GitHub Pages tidak aktif?**
- Buka: https://github.com/reskt48-lab/taskly/settings/pages
- Set: Deploy from branch → main → / (root) → Save

**Aplikasi tidak update?**
- Clear cache di HP
- Hard refresh (Ctrl+F5 di laptop)

**Install button tidak muncul?**
- Pastikan HTTPS aktif
- Gunakan Chrome (Android) atau Safari (iOS)
- Icon harus sudah ada (generate dulu)
